# I have to enter description of my task
The objective of this task is to demonstrate scalable data analysis on a large dataset using Apache Spark with PySpark. I used the NYC Yellow Taxi trip data (~1.5 GB+) to perform distributed processing and derive meaningful insights. The dataset was cleaned, transformed, and analyzed to extract hourly trends, fare patterns, and passenger statistics. Key operations included handling missing values, feature extraction (hour from timestamps), and grouped aggregations using PySpark’s DataFrame API. The analysis results were saved to distributed storage as CSV files, showcasing Spark’s ability to efficiently handle big data workloads.
